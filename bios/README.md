# BIOS ROMs

`./scripts/fetch-bios.sh` downloads these from 3dodev.com and checks their MD5s.
They are copyrighted firmware and are not committed to this repo. To use your
own dumps instead, drop them here with the same file names (or set
`TDO_BIOS_DIR`).

|---|---|---|

| panafz1.bin | Panasonic FZ-1 (U) | f47264dd47fe30f73ab3c010015c155b |
| panafz10-norsa.bin | FZ-10, RSA check disabled (runs unsigned discs) | 1477bda80dc33731a65468c1f5bcbee9 |
